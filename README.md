# Antoine Brachet

Développeur web et mobile, étudiant à l'IIM. Je construis des applications complètes, de la base de
données à l'interface, souvent pour régler un problème concret autour de moi : organiser un festival
entre amis, taguer ma bibliothèque DJ dans le train, préparer une draft League of Legends.

## Projets

| Projet | En bref | Stack |
| --- | --- | --- |
| [**Vialcrm**](https://github.com/antoine721/Gestion-stock) | Hub d'organisation de festival : invités et paiements, bar, liste de courses calculée à partir de ce que boit chaque invité, planning | Angular · Vercel · Postgres |
| [**MyTags**](https://github.com/antoine721/MyTags) | Taguer ~5 000 morceaux DJ depuis l'iPhone hors ligne, puis écrire les tags dans Serato depuis le Mac | SwiftUI · Cloudflare Workers · Python |
| [**DraftPredict**](https://github.com/antoine721/DraftPredict) | Probabilité de victoire en temps réel pendant la draft League of Legends, suggestions de picks et builds | React · Fastify · Electron |
| [**WikiPacks**](https://github.com/antoine721/wikipacks) | Chaque article Wikipédia est une carte : boosters, collection, comparaison entre amis | React · Tailwind |
| [**RD2-SIMULATION**](https://github.com/antoine721/RD2-SIMULATION) | Une grammaire d'actions qui génère tout ce qu'un joueur peut faire, au lieu de l'écrire à la main | JavaScript |
| [**Genuary 2026**](https://antoine721.github.io/genuary/) | 31 œuvres d'art génératif, univers vaporwave / Y2K | JavaScript |

## Stack

- **Langages** : TypeScript, JavaScript, Swift, Python, C#
- **Front** : React, Angular, Vue
- **Back** : Node (Fastify), serverless (Vercel, Cloudflare Workers), PostgreSQL
- **Aussi** : Electron, SwiftUI, Unity (XR)
